# Meet

Instant 1-on-1 video meetings — share a link, one click to connect

**Live:** https://meet.freeappstore.online

A free app on [FreeAppStore](https://freeappstore.online). App id: `meet`.

## Develop

```bash
pnpm install
pnpm dev
pnpm build
pnpm run typecheck
pnpm test
```

Before publishing, run `fas check` (`npm i -g @freeappstore/cli`). Pushing to `main` deploys the app.
